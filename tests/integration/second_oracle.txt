# The differences from the second oracle: the pdfTeX of the official TeX Live 2026 for x86_64-linux, which is what CI's Linux job compares with, through RSTEX_ORACLE_DIR.  run.py reads this
# only then, in place of known_divergences.txt.  A line is the case, what is allowed, and why.
#
#   differs:-N+M:HASH   The case differs, and these are all its differences.  Each log, terminal, PDF object and dvitype line is compared; HASH covers what lies between the first and the last line that
#                       differ, N lines of the oracle's and M of the candidate's, with TeX's wrapping and the tree's place taken out.  Any other difference, or none, fails: the failure prints what it is now.
#   random:-N+M:HASH    The same, or it agrees.  For an oracle that gives two answers on one input.
#   dies:SIGNAL:+M:HASH The oracle dies by this signal, and the candidate ends by itself, and this is the candidate's result, M lines with this hash, since there is nothing to compare it with.
#
# Past 2^31 rstex follows docs/PORTING.md section 11: where an i64 in a sum already holds Arch's value it keeps that, and every word wraps, as on this pdfTeX.  So a line with W below is a decision made in such an i64, with what
# follows from it, where rstex gives what Arch's gives on the same tree; that comparison stays exact in the ordinary run of this tool.  Where a line has M, S or O alone, the same.  Each was seen by running both binaries on both trees.
