#   differs:-N+M:HASH    The case differs, and these are all its differences.  Each log, terminal, PDF object and dvitype line is compared; HASH covers what lies between the first and the last line that

#                        updmap has run for them: run.py's font_map().  Any other difference, or none, fails: the failure prints what it is now.
#   banner:-N+M:HASH     The same, or it agrees, as it does with the feature oracle-banner, whose version string is the oracle's.
#   candidate:+M:HASH    The same of the candidate's lines alone, or it agrees: the oracle's are not the same twice.
#   dies:SIGNAL:+M:HASH  The oracle dies by this signal, and the candidate ends by itself and gives this.
