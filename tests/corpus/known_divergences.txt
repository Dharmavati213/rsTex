# The accepted differences from the oracle: run.py reads this.  A line is the entry, what differs in it level by level, then a reason a reader can check.  tests/corpus/README.md, "The accepted list".
#
#   ID MODE:LEVEL=TOKEN,LEVEL=TOKEN... [MODE:...] REASON
#
# MODE is both, last-pass or from-scratch, and a mode the line does not name has to agree.  LEVEL is L0, the side files; L1 and L2, the trace and the box dumps; L4, the page content;
# L5, the rest of the PDF; L6, the uncompressed bytes; log, in the form the entry is judged in; log_strict, the whole log of a regression test; exit.  L1, L2 and L6 come from the instrumented pass, which is
# one per entry from the last pass's state, whichever mode runs it, so they go under last-pass or both.
#
#   -N+M:HASH    N lines of the oracle's and M of the candidate's from the first line that differs at that level to the last, and a hash of those lines, with the home directory, the tree, the output directory
#                and the engine's own directory taken out, and TeX's wrapping undone.  The same on any machine.
#   O/C          For exit: the oracle's status and the candidate's.
#
# A level this run judges and the line names has to give that token, and one it does not name has to agree: any other difference fails, and the failure prints what it is now, which is for a reader to look at and
# not to paste.  So a level left out of a run (--box-log never, --no-l6) neither fails nor passes a line.  L1 runs on a listed entry whatever the oracle takes, as the CPU limit depends on the machine.
# An entry with no difference left at any level judged is identical, and the summary says AGREES.
#
# A token on a private entry is an HMAC under a key made from the document, so it carries no text, and it cannot be tried against a guess without the document.
#
# The banner: the document copies the version string, typesets it, or takes the CRC of the job id that holds it, beyond the one place L6 masks.
# All of these agree with the feature oracle-banner, tests/gate.sh --oracle-banner, but for the date of the format in the two that take the CRC.
