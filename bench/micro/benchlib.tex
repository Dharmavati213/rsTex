% benchlib.tex -- timing harness for the rstex micro-benchmarks.
%
% Every benchmark file does \input benchlib and then calls
%   \bench{name}{tree}{setup}{body}             ops = 10^tree-letter
%   \benchx{name}{tree}{inner}{setup}{body}     ops = 10^tree-letter * inner
% tree letters: a=10 b=100 c=1e3 d=1e4 e=1e5 f=1e6 g=1e7.
% Output on the terminal and log, one line per benchmark:
%   BENCH <name> ops=<n> inner=<k> t=<elapsed in 1/65536 s>
% The body is reached through a tree of parameterless macros, so each op
% pays about 1.11 extra macro expansions: run.py subtracts the "empty"
% benchmark's per-op time to give net ns/op.
%
% Engine requirements: \pdfresettimer, \pdfelapsedtime, e-TeX \numexpr.
% Files 01-08, 11, 12 run under plain pdfTeX and under the LaTeX format
% (no \documentclass); 09, 10, 13 need the LaTeX format and packages.

  \begingroup #4\relax
  \long\def\B{#5}%
  \pdfresettimer
  \csname bT@#2\endcsname
  \edef\bench@t{\the\pdfelapsedtime}%
  \immediate\write16{BENCH #1 ops=\the\numexpr\csname bN@#2\endcsname*#3\relax\space inner=#3 t=\bench@t}%
  \endgroup}

on a covering of a space may be glued together into a global object, provided
that suitable compatibility conditions are satisfied on the overlaps. In the
setting of algebraic geometry one replaces open coverings by faithfully flat
